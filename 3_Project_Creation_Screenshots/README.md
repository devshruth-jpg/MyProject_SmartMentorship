## Jira setup (quick steps)

1. Sign in at https://www.atlassian.com/software/jira (free plan is enough).
2. Create project: choose the Scrum template, name it "Alumni Mentorship Platform".
3. Import the backlog: Settings > System > External System Import > CSV, upload `jira_backlog.csv` and map Summary, Issue Type, Priority and Description.
4. Take the screenshots listed above and save them in `Jira/`.

Delete the `.gitkeep` files after adding screenshots (optional).
